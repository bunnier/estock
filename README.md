# 码盯·撸得金

码盯·撸得金是一个在 VS Code 状态栏查看 A 股、港股股票与指数行情的插件。

> 边码字，边盯盘，撸得真金。

## 功能

- 在状态栏同时展示多只股票。
- 支持沪深 A 股、港股，以及恒生指数、恒生科技指数等港股指数。
- ETF、LOF 等场内基金在悬停详情和详情页展示基金净值与溢价率。
- 支持股票池管理和状态栏展示列表。
- 点击状态栏股票即可切换展示内容。
- 交易时段自动刷新，休市后显示「休市」。
- 异动提醒：配置周期内股价达到阈值时，在状态栏显示短时提醒。
- 支持手动刷新、查看详情、调整颜色和展示格式。

## 安装

### 从插件市场安装

在扩展面板搜索「码盯·撸得金」「码盯」或「estock」，点击安装。

## 使用

安装后，状态栏会显示默认关注的股票。

### 添加股票

打开命令面板，执行 `estock: 添加股票到股票池`，输入股票代码或中文名称即可添加。

输入代码时会直接添加；输入中文名称时会展示搜索候选，选择后添加。

支持的输入格式：

| 类型 | 格式 | 示例 |
|------|------|------|
| A 股代码 | `sh` / `sz` 前缀加 6 位数字 | `sh000001`、`sz000001` |
| 港股代码 | `hk` 前缀加 5 位数字 | `hk00700`、`hk00388` |
| 港股指数 | `hk` 前缀加字母代码 | `hkHSI`、`hkHSTECH`、`hkHSCEI` |
| 指数缩写 | 常见港股指数缩写 | `HSI`、`HSTECH`、`HSCEI` |
| 名称关键词 | 股票或指数名称关键词 | `中国平安`、`恒生科技` |

建议使用带市场前缀的代码，以区分上证指数 `sh000001` 和平安银行 `sz000001` 等数字代码相同的标的。旧版配置中的 A 股 6 位、港股 5 位裸代码仍然兼容，并会按原有规则自动识别市场。

中文名称搜索支持 A 股、港股股票和港股指数，例如输入 `恒生科技` 会同时列出恒生科技指数与相关 ETF，选择后即可添加。

### 切换状态栏股票

有两种方式：

1. 直接点击状态栏上的某只股票，然后从股票池中选择要展示的股票。
2. 打开命令面板，执行 `estock: 切换状态栏展示股票`，先选择状态栏位置，再选择股票。

### 查看详情

打开命令面板，执行 `estock: 查看股票详情`，可以查看当前价、涨跌、今开、最高、最低、振幅、成交量、更新时间和雪球详情页。若目标为 ETF、LOF 等场内基金，还会额外展示基金净值及其与当前价之间的溢价率，例如 `基金净值：1.1248（溢价率：-1.05%）`。

### 查看股票池详情

打开命令面板，执行 `estock: 查看股票池股票详情`，可以在输出面板中以表格方式查看股票池内全部股票的完整详情。股票池中存在基金时，表格会增加「基金净值」列，同时给出溢价率。

### 手动刷新

打开命令面板，执行 `estock: 刷新股票行情`，会立即刷新股票行情。

### 移除股票

打开命令面板，执行 `estock: 从股票池删除股票`，选择要删除的股票即可。

## 配置

在设置中搜索 `estock` 可以调整插件行为。

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `estock.watchList` | `["sh601318", "hk00700", "sz002027", "sh601899"]` | 股票池，保存所有关注的股票。 |
| `estock.displayList` | `["hk00700", "sh601318", "sz002027"]` | 状态栏展示列表，决定显示哪些股票和显示顺序。 |
| `estock.maxDisplay` | `3` | 展示列表为空时，最多从股票池中展示几只股票。 |
| `estock.refreshInterval` | `10` | 自动刷新间隔，单位为秒，最小值为 5。 |
| `estock.priceAlertEnabled` | `true` | 是否显示异动提醒。 |
| `estock.priceAlertWindowSeconds` | `120` | 异动提醒统计周期，单位为秒，可填写任意不小于 1 的整数。 |
| `estock.priceAlertThresholdPercent` | `1` | 异动提醒阈值，按配置周期内的涨跌幅计算，最小值为 0.1。 |
| `estock.priceAlertColor` | `"#FFD700"` | 异动提醒颜色。 |
| `estock.displayFormat` | `"${name} ${changePercent} (${currency}${price})"` | 状态栏展示格式。 |
| `estock.statusBarAlignment` | `"center"` | 状态栏位置，可选 `left`、`center`、`right`。 |
| `estock.colorUp` | `"#FAAFA0"` | 上涨颜色。 |
| `estock.colorDown` | `"#4EC9B0"` | 下跌颜色。 |
| `estock.colorFlat` | `"#CCCCCC"` | 平盘颜色。 |
| `estock.colorClosed` | `"#AAAAAA"` | 休市颜色，收盘后统一使用。 |

### 展示格式

`estock.displayFormat` 支持以下变量：

| 变量 | 说明 | 示例 |
|------|------|------|
| `${name}` | 股票名称，包含市场标识。 | `腾讯控股(H)` |
| `${price}` | 当前价。 | `421.00` |
| `${currency}` | 金额货币符号，A股为 `¥`，港股为 `$`。 | `$` |
| `${change}` | 涨跌额。 | `+1.20` |
| `${changePercent}` | 涨跌幅。 | `+0.29%` |
| `${volume}` | 成交量。 | `7849461` |

示例：

```json
"${name} ${changePercent} (${price})"
```

## 交易时间

| 市场 | 交易/竞价刷新时段 | 延迟刷新至 |
|------|------------------|------------|
| A 股 | 周一至周五 9:15-11:30、13:00-15:00 | 11:35、15:05 |
| 港股 | 周一至周五 9:00-12:00、13:00-16:10 | 12:15、16:25 |

交易或竞价结束后的延迟刷新期内，插件会继续更新行情以等待免费行情源稳定，但状态栏会按休市样式展示。

插件会按 A 股和港股各自的市场时间判断是否刷新。A 股和港股不会互相影响：例如港股休市但 A 股开市时，A 股仍会刷新，港股会显示「休市」。

休市判断会参考内地和香港公众假期。遇到交易所临时休市、特殊交易安排或节假日调整时，实际状态可能以交易所公告为准。

## 数据说明

本插件使用免费的公开行情来源，无需配置账号或密钥。免费行情通常会有延迟，尤其是港股行情，状态栏展示仅用于快速查看，不适合作为交易依据。

ETF、LOF 的基金净值取行情接口提供的盘中参考净值（IOPV），缺少参考净值时取最新单位净值；溢价率按「当前价 / 净值 - 1」实时计算，正数表示溢价，负数表示折价。港股基金与部分品种不提供净值，此时不展示该行。
